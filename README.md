# PromptGrinder Tap

## How do I install these formulae?

`brew install promptgrinder/tap/<formula>`

Or `brew tap promptgrinder/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "promptgrinder/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
